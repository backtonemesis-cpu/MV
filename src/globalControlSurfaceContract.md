# Global field surface contract

The Account field is the visual reference for value-entry and value-selection boxes.

- Genuine text/number/date/month/search inputs, selects and textareas use `var(--field)`.
- Semantic custom listbox/combobox triggers use `var(--field)`.
- Slate Grey therefore renders these field surfaces as `#1F2937`.
- Buttons, tabs, cards, checkboxes/radios, range/color/file controls and menu option panels are outside this contract.
- This contract changes background colour only; typography, geometry, indicators and finance/date semantics remain unchanged.
